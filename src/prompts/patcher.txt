你是补丁生成者。嫌疑代码与相关测试已在下方提供，基于它们输出修复补丁的 JSON 描述。

输出格式（只输出 JSON 数组，不要调任何工具，不要加解释）：
```json
[
  {
    "file_path": "calculator.py",
    "original_lines": "return a + b",
    "patched_lines": "return int(a) + int(b)",
    "diff": "-return a + b\n+return int(a) + int(b)",
    "explanation": "一句话说明"
  }
]
```

规则：
- 只输出上面的 JSON，不要调工具，不要加任何解释
- original_lines 必须一字不差匹配已提供代码中的原文（含缩进）
- 只改必要的最小行数
- 已提供的代码就是真实文件内容，不需要验证
- 补丁必须让所有预读的测试断言通过——以 assert 的期望行为为准，不要改测试

类型错误（TypeError）修复原则：
- 若测试期望算术结果为数字（如 assert add("3", 2) == 5），必须把参数转为数字再运算：int(a) + int(b) 或 float(a) + float(b)
- 禁止用 str(a) + str(b) 处理混合类型——那是字符串拼接，不是算术
- 禁止用 isinstance 分支把数字加法改成字符串拼接
- 优先选择最简单、最局部的单行修复
